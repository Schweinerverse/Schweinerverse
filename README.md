# SITWS 5 - Eternal Snow

Snow in the Water Simulator 5: a browser action-RPG prototype built with three.js.

- `index.html` - the whole game (three.js r128 + post-processing loaded from jsDelivr)
- `tree.glb` - decimated spruce model used for the forest (falls back to simple cones if missing)
- `render.yaml` - Render static-site blueprint

Controls: WASD move, Shift sprint, Space roll, LMB/J light combo, RMB/K heavy attack, Tab/Q/MMB lock-on, mouse or arrow keys for camera, wheel to zoom.
